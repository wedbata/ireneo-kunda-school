📋 Quick Setup Guide
Follow these simple steps to complete the setup:
1
Run the Setup Script
Open Terminal/CMD in the project folder and run one of these commands:
node setup-assets.js
Or on Windows:
setup-assets.bat
Or Python:
python setup-assets.py
2
Verify Installation
Check that these folders are created with files:
images/logo/logo.png
images/gallery/*.jpg (your images)
3
Open Your Website
Refresh your browser and navigate to the Gallery page to see all images with your logo in the navbar.
